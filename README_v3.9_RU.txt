КАК СОХРАНЯТЬ АККАУНТЫ ПОСЛЕ ОБНОВЛЕНИЙ:
В текущем server.js аккаунты хранятся в файле accounts.json внутри DATA_DIR.
Если DATA_DIR указывает на обычную файловую систему Render, данные могут исчезнуть при redeploy/restart.

ВАРИАНТ С RENDER PERSISTENT DISK (требуется тариф Render с поддержкой диска):
1. Откройте Render Dashboard > ваш Web Service > Disks.
2. Добавьте Persistent Disk с Mount Path: /var/data (при наличии этой возможности на тарифе).
3. В Render > Environment добавьте DATA_DIR со значением /var/data.
4. Сохраните настройки и дождитесь успешного деплоя.
5. Создайте тестовый аккаунт, сделайте redeploy и проверьте вход.
6. Для защиты от потери данных делайте резервные копии accounts.json с диска.

ВАЖНО: аккаунты, созданные ДО подключения диска, не переносятся автоматически.
Чтобы сохранить существующие аккаунты, нужно заранее перенести старый accounts.json на диск.
На бесплатном Render постоянный диск обычно недоступен: потребуется внешняя база данных
и отдельное изменение server.js для работы с ней. Не создавайте важные аккаунты до настройки хранения.
Никогда не загружайте accounts.json, пароли или ADMIN_SECRET в публичный GitHub.
